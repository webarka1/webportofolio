Panduan Edit — Portofolio Arka Arthand Syach

File proyek ini ada 4: index.html, style.css, script.js, dan folder images/. Taruh semuanya dalam satu folder yang sama — kalau dipindah-pindah, link antar file bisa putus.

Cara buka: tinggal double-click index.html, langsung terbuka di browser. Tidak perlu install apa-apa.

1. Struktur Cepat

File Isinya Kapan diedit
index.html Teks, struktur section, link Ganti nama, teks, link sosial media
style.css Warna, ukuran, jarak, animasi Ganti warna/tampilan
script.js Data (achievements, projects, dll) + logika interaktif Ganti riwayat rank, daftar proyek, tools
images/ Semua foto/gambar Taruh file gambar di sini

Tiap section di index.html ditandai komentar seperti ini, tinggal Ctrl+F cari kata-katanya:

<!-- ===================== NAMA SECTION ===================== -->

Section yang ada: HEADER, FULLSCREEN NAV, HERO, ABOUT, CAROUSEL, PROJECTS, SKILLS, MEDIA / YOUTUBE, ACHIEVEMENTS, CONNECTIONS + TROPHIES, CONTACT, FOOTER.

2. Ganti Gambar (paling sering ditanya)

Cara paling gampang: buka images/BACA-DULU.txt, isinya daftar nama file yang dicari kode. Taruh foto kamu di folder images/ dengan nama persis seperti di daftar itu (huruf kecil semua, pakai tanda - bukan spasi). Contoh: foto hero disimpan sebagai images/hero-background.jpg.

Aturan pentingnya:

  • Nama harus sama persis (hero-background.jpg, bukan Hero Background.JPG).
  • Kalau file belum ada, otomatis muncul kotak gradient sebagai placeholder — tidak akan error.
  • Kalau mau pakai .png bukan .jpg, cari baris data-label="....jpg" di index.html/script.js dan src="images/....jpg" di sebelahnya, ganti keduanya jadi .png.
  • Gambar otomatis di-crop rapi mengisi kotaknya (object-fit:cover), jadi tidak perlu crop manual dulu.

Kalau mau menambah gambar baru yang belum ada di kode (misal galeri baru), copy pola ini:

<div class="ph" data-label="nama-file.jpg">
  <img src="images/nama-file.jpg" alt="Deskripsi"
       onload="this.parentElement.classList.add('has-img')"
       onerror="this.remove()">
</div>

3. Ganti Teks Dasar (nama, sekolah, bio)

Semua ada di index.html, tandanya komentar <!-- EDIT TEXT DI SINI --> atau <!-- GANTI ... DI SINI -->.

Titik yang paling penting:

  • Nama besar di Hero: cari <h1>ARKA<br>ARTHAND<br>SYACH</h1>
  • Deskripsi singkat di Hero: paragraf tepat di bawah hero-meta
  • About Me: bagian id="about" — ada <dl class="about-facts"> untuk Nama/Sekolah/Kelas/Achievement
  • Brand header: <div class="brand">ARKA ARTHAND SYACH<small>SMKS BINONG PERMAI</small></div>

4. Ganti Warna

Semua warna diatur di satu tempat di paling atas style.css:

:root{
  --navy:#061A2B;    /* warna gelap utama (header, background section navy) */
  --navy2:#0A2A44;   /* varian navy untuk kartu project */
  --white:#FFFFFF;
  --off:#F4F4F2;      /* off-white untuk background section terang */
  --black:#111111;
  --accent:#D71920;   /* merah aksen — tombol, garis aktif, hover */
}

Ganti nilai hex-nya saja, otomatis berubah di semua section yang pakai variabel itu.

5. Riwayat Achievements (Rank per semester)

Ada di script.js, cari komentar:

// ACHIEVEMENTS — RB-STYLE PAGER (EDIT RIWAYAT RANK DI SINI)

Bentuknya array — urutan dari sekarang ke masa lalu. Tambah/hapus/edit baris sesuai kebutuhan:

{rank:"1", period:"XII TJKT 1", school:"SMKS Binong Permai", tier:"gold"},
  • rank → angka rank (bisa teks bebas, misal "2–3")
  • period → nama kelas/semester
  • school → nama sekolah
  • tier → "gold" (rank 1), "silver" (rank 2–3), atau "bronze" (top 10) — ini yang menentukan warna trofi 3D otomatis

Jangan lupa: kalau jumlah barisnya berubah, tidak perlu update angka "Total Riwayat" secara manual — sudah otomatis ambil dari jumlah array (achHistory.length).

6. Riwayat Connections (wali kelas, teman sekelas)

Masih di script.js, cari:

// CONNECTIONS PAGER — EDIT RELASI DI SINI

Setiap periode sekolah punya rows — bebas tambah baris label baru:

{title:"SMKS Binong Permai", sub:"Kelas X – XII", rows:[
  {label:"Wali Kelas", val:"Kelas X: Pa Dwi Karyanto<br>Kelas XI–XII: Pa Sukardi"},
  {label:"Guru Produktif", val:"Pa Andre, Pa Panji, Pa Dwi, Pa Dede Imam"},
]},

Pakai <br> di dalam teks kalau mau ganti baris.

7. Projects (kartu proyek + popup detail)

Ada di dua tempat yang harus disinkronkan:

a) index.html — cari section PROJECTS, tiap kartu punya atribut data-project="mikrotik" dstnya. Ganti teks judul/deskripsi singkat di sini.

b) script.js — cari:

// PROJECTS — RICH DETAIL POPUP (EDIT KONTEN PROYEK DI SINI)

Ini isi popup saat tombol "VIEW PROJECT" diklik. mikrotik, website, arduino, editing harus sama persis dengan data-project="..." di HTML. Kalau mau tambah proyek ke-5:

  1. Tambah <article class="proj-item reveal" data-project="proyek-baru">...</article> di HTML.
  2. Tambah entry proyekBaru:{tag:"...", title:"...", img:"...", body:"...", tags:[...]} di JS.

8. Skills & Tools (popup Premiere Pro, MikroTik, dll)

Di script.js, cari:

// SKILLS — TOOL BADGE POPUP (EDIT TOOLS DI SINI)

Ada 4 kategori: web, networking, hardware, creative — sesuai data-skill="..." di section Skills pada index.html. Tiap tool:

{abbr:"Pr", color:"#26205c", name:"Premiere Pro", img:"premiere-pro.jpg", desc:"..."}
  • abbr → 2 huruf yang muncul di badge kecil
  • color → warna badge
  • img → nama file di folder images/
  • desc → deskripsi tool

9. Media / YouTube

Section MEDIA / YOUTUBE di index.html:

  • Nama channel, jumlah subscriber → cari <!-- GANTI JUMLAH SUBSCRIBER -->
  • Link tiap video → cari <!-- GANTI LINK VIDEO (href) DI SINI -->, ganti href="javascript:void(0)" jadi href="https://youtube.com/watch?v=..."
  • Judul/tanggal/views video → cari <!-- GANTI JUDUL VIDEO --> dst di dalam kartu yang sama
  • Thumbnail video → taruh images/thumbnail-1.jpg, thumbnail-2.jpg, thumbnail-3.jpg

10. Footer (WhatsApp, foto)

Section FOOTER di index.html:

<a href="https://wa.me/6281280458402">WA Bisnis — 0812-8045-8402</a>

Format link WA: https://wa.me/62 + nomor tanpa angka 0 di depan dan tanpa spasi/strip. Contoh: 0812-8045-8402 → 6281280458402.

Foto footer → images/footer-photo.jpg.

11. Contact (Instagram, GitHub, Email)

Section CONTACT, cari <!-- GANTI LINK ... DI SINI -->, ganti href="#" dengan link asli. Untuk email pakai format href="mailto:emailkamu@gmail.com".

12. Troubleshooting

Masalah Penyebab Solusi
Gambar tidak muncul, tetap kotak gradient Nama file tidak persis sama, atau salah folder Cek ejaan huruf besar/kecil & lokasi (harus di dalam images/)
Popup tidak muncul saat diklik data-skill/data-project di HTML tidak cocok dengan key di JS Pastikan penulisannya sama persis (huruf kecil semua)
Tampilan berantakan setelah edit CSS Ada kurung kurawal { } yang kehapus tidak sengaja Cek jumlah { dan } seimbang di bagian yang diedit
Warna tidak berubah Edit warna di tempat lain, bukan di :root Ganti hanya nilai hex di variabel --navy, --accent, dll

13. Kalau Mau Online-kan (Hosting)

Situs ini statis (tidak butuh server backend), jadi bisa langsung di-upload ke:

  • GitHub Pages (gratis) — upload folder ini ke repo GitHub, aktifkan Pages di Settings.
  • Netlify / Vercel (gratis) — drag & drop foldernya ke dashboard mereka.

Tidak perlu ubah kode apa pun untuk hosting di layanan-layanan itu.
